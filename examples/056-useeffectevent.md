# Example: useEffectEvent and Non-Reactive Event Logic

This runnable example simulates a chat connection with a local timer. Changing the selected room cancels the previous timer and starts synchronization for the new room. Changing the theme or notification preference does not restart that synchronization.

When the simulated connection reports success, its callback records the room that connected and uses the latest theme and notification preference through **useEffectEvent**. The demo makes no network requests.

## Requirements

Use React 19.2 or later. The React version generated by the project setup must include **useEffectEvent**, and the Hooks lint plugin should be current enough to recognize it.

## Create the project

~~~sh
npm create vite@latest effect-event-demo -- --template react
cd effect-event-demo
npm install
~~~

Replace the generated files with the following, then start the development server:


## src/App.jsx

~~~jsx
import { useEffect, useEffectEvent, useState } from "react";

const ROOMS = [
  { id: "general", label: "General" },
  { id: "design", label: "Design" },
  { id: "weekend", label: "Weekend plans" },
];

function ChatRoom({ roomId, theme, showNotifications }) {
  const [connectionEvents, setConnectionEvents] = useState([]);
  const [notification, setNotification] = useState(null);

  const onConnected = useEffectEvent((connectedRoomId) => {
    const eventTheme = theme;
    const shouldNotify = showNotifications;

    setConnectionEvents((currentEvents) => [
      {
        id: currentEvents.length + 1,
        roomId: connectedRoomId,
        theme: eventTheme,
        notified: shouldNotify,
      },
      ...currentEvents,
    ]);

    if (shouldNotify) {
      setNotification({
        roomId: connectedRoomId,
        theme: eventTheme,
      });
    } else {
      setNotification(null);
    }
  });

  useEffect(() => {
    const timeoutId = window.setTimeout(() => {
      onConnected(roomId);
    }, 1400);

    return () => {
      window.clearTimeout(timeoutId);
    };
  }, [roomId]);

  return (
    <section className="room-panel" aria-labelledby="room-title">
      <div className="room-header">
        <div>
          <p className="eyebrow">Active synchronization</p>
          <h2 id="room-title">{roomId}</h2>
        </div>
        <span className="connection-status">
          Simulating connection
          <span className="status-dot" aria-hidden="true" />
        </span>
      </div>

      <p className="room-description">
        A local timer simulates the room's connected event. Changing rooms
        restarts the timer. Changing the theme or notification setting does not.
      </p>

      <div className="waiting-card" role="status">
        The demo will record a connection event after the mock connection
        completes.
      </div>

      {notification && (
        <div
          className={"notification notification--" + notification.theme}
          role="status"
          aria-live="polite"
        >
          <span className="notification-mark" aria-hidden="true">
            ✓
          </span>
          <span>
            Connected to <strong>{notification.roomId}</strong>
            <span className="notification-detail">
              Notification used the latest {notification.theme} theme.
            </span>
          </span>
        </div>
      )}

      <div className="event-log">
        <div className="event-log-heading">
          <h3>Connection event log</h3>
          <span>{connectionEvents.length} events</span>
        </div>

        {connectionEvents.length === 0 ? (
          <p className="empty-state">Waiting for the first connection event…</p>
        ) : (
          <ol>
            {connectionEvents.map((event) => (
              <li key={event.id}>
                <span>
                  Connected to <strong>{event.roomId}</strong>
                </span>
                <span>
                  {event.notified
                    ? event.theme + " notification"
                    : "notification disabled"}
                </span>
              </li>
            ))}
          </ol>
        )}
      </div>
    </section>
  );
}

export default function App() {
  const [roomId, setRoomId] = useState(ROOMS[0].id);
  const [theme, setTheme] = useState("light");
  const [showNotifications, setShowNotifications] = useState(true);
  const selectedRoom = ROOMS.find((room) => room.id === roomId) ?? ROOMS[0];

  function handleRoomChange(event) {
    setRoomId(event.target.value);
  }

  return (
    <main className="page-shell">
      <header className="page-header">
        <p className="eyebrow">React Hooks · Chapter 056</p>
        <h1>Effect Events read current values</h1>
        <p className="intro">
          Change the presentation settings while the mock room is connecting.
          Only a room change should restart the connection synchronization.
        </p>
      </header>

      <section className="panel controls-panel" aria-labelledby="controls-title">
        <div className="section-heading">
          <div>
            <p className="eyebrow">Reactive inputs</p>
            <h2 id="controls-title">Chat settings</h2>
          </div>
          <span className="room-badge">{selectedRoom.label}</span>
        </div>

        <div className="controls-grid">
          <label>
            Connected room
            <select value={roomId} onChange={handleRoomChange}>
              {ROOMS.map((room) => (
                <option key={room.id} value={room.id}>
                  {room.label}
                </option>
              ))}
            </select>
          </label>

          <label>
            Notification theme
            <select
              value={theme}
              onChange={(event) => setTheme(event.target.value)}
            >
              <option value="light">Light</option>
              <option value="dark">Dark</option>
            </select>
          </label>
        </div>

        <label className="checkbox-control">
          <input
            type="checkbox"
            checked={showNotifications}
            onChange={(event) => setShowNotifications(event.target.checked)}
          />
          Show a notification when connected
        </label>
      </section>

      <ChatRoom
        roomId={roomId}
        theme={theme}
        showNotifications={showNotifications}
      />

      <section className="explanation-panel" aria-labelledby="why-title">
        <p className="eyebrow">Why the split matters</p>
        <h2 id="why-title">One reactive input, two latest settings</h2>
        <ul>
          <li>
            <strong>Room:</strong> selects the resource, so it is a dependency
            of the Effect.
          </li>
          <li>
            <strong>Theme and notification preference:</strong> only affect how
            the connection event is handled, so the Effect Event reads their
            latest values.
          </li>
          <li>
            <strong>Connected room:</strong> is passed to the Effect Event as an
            argument so the log identifies the room that produced that event.
          </li>
        </ul>
      </section>

      <footer className="page-footer">
        <p>
          The connection is simulated with a timer. No messages, user data, or
          network requests leave this page.
        </p>
      </footer>
    </main>
  );
}
~~~

## Try the behavior

1. Select a room and wait for the simulated connection event.
2. Select another room. Its event appears after the new timer completes.
3. Select a different theme while the connection is pending. The Effect does not restart; the later notification uses the selected theme.
4. Turn notifications off while the connection is pending. The connection event is still recorded, but it does not display a notification.
5. Change the theme after a connection has completed. The old log entry stays the same; a later connection event uses the latest theme.

## Read the important code

The Effect's dependency list contains only the value that selects the connection:

~~~jsx
useEffect(() => {
  const timeoutId = window.setTimeout(() => {
    onConnected(roomId);
  }, 1400);

  return () => window.clearTimeout(timeoutId);
}, [roomId]);
~~~

The room ID is passed as an argument because it identifies the connection event created by this Effect instance. The Effect Event reads the latest theme and preference:

~~~jsx
const onConnected = useEffectEvent((connectedRoomId) => {
  const eventTheme = theme;
  const shouldNotify = showNotifications;

  // Record the event and optionally show its notification.
});
~~~

Do not add **onConnected** to the dependency array or call it from a button handler. It belongs to the Effect that owns the mock connection.

## Practice changes

1. Add a message input and send messages from its form submit handler. Do not send a message from an Effect Event.
2. Add a server address setting that truly selects a different connection. Make it an Effect dependency.
3. Add a current message count that appears in a connection notification without causing the room connection to restart.
4. Change the mock connection delay and confirm that switching rooms cancels the previous timer.
